# Return Market List

쿠팡 등 반품·리퍼·전시 상품 기획전에서 직접 확인한 상품 링크를 보존하고 비교하는 정적 개인용 목록 사이트입니다.

## 실행

`index.html`을 브라우저로 열면 동작합니다. 로컬 서버로 확인하려면 다음을 실행합니다.

공개 사이트: `https://04pril.github.io/apple-return-market/`

```powershell
python -m http.server 4173 --directory .\return-market
```

그 다음 `http://localhost:4173`으로 엽니다.

## 기록 방식

- 상품은 수동으로 추가합니다. 상품명, URL, 가격, 상태, 메모를 기록할 수 있습니다.
- 모든 데이터는 해당 브라우저의 `localStorage`에 저장됩니다.
- `CSV 내보내기`로 외부 백업을 만들고, `CSV 불러오기`로 나중에 복원합니다.
- 판매 가격과 반품 상태는 실시간 정보가 아닙니다. 구매 직전에 원 판매 페이지에서 다시 확인해야 합니다.

## 초기 출처

- Apple 반품상품 SALE: `https://pages.coupang.com/p/163488?sourceType=oms_share`
- 2026-08-05에 Apple 반품마켓 6개 카테고리의 상품 응답을 끝까지 수집한 2,279개 항목을 기본 목록에 포함했습니다.
- 확인 가능 995개, 품절 기록 1,284개입니다.
- 카테고리: 아이폰 349개, 아이패드 427개, 맥 402개, 애플워치 161개, 에어팟 143개, 액세서리 797개.
- 사용자가 제공한 DCInside 댓글 제보 링크는 공식 카탈로그와 productId/vendorItemId를 대조해 중복을 줄이고, 아이패드·액세서리·에어팟 등 실제 상품 카테고리에 함께 표시합니다. 제보 출처는 카드 메모와 원문 URL에만 남깁니다.
- 단축 링크 9개(`ftlA7UTZT2`, `e6bY9b2Lg4`, `eSDmqlO6nc`, `eSDoTkN2MS`, `eamO5AzJ4S`, `d1MM2AnOIS`, `eDW3GE`, `emcg2NwG5Y`, `ehlTgLCP9M`)는 최종 리다이렉트에서 productId/itemId/vendorItemId를 해석했습니다.
- 확인된 새 옵션은 M5 아이패드 프로 11, M4 아이패드 프로 11용 매직 키보드 3개 등이며, 반품 등급·가격·재고를 확인한 경우 카드 메모에 확인 시점의 값을 기록했습니다. 가격과 재고는 실시간 정보가 아니므로 구매 전에 다시 확인해야 합니다.
- `eSDmqlO6nc`와 `eSDoTkN2MS`는 같은 productId지만 서로 다른 반품등급/vendorItemId라 각각 보존합니다. `eamO5AzJ4S`와 `ehlTgLCP9M`은 같은 productId/itemId/vendorItemId로 연결되어 하나의 옵션으로 묶었습니다.
- productId 8179163270, 8156707109, 8470557531, 8404740360, 8527859660, 8179312949도 해당 상품 카테고리에 보존합니다. 8179312949는 사용자가 다시 보낸 `https://www.coupang.com/vp/products/8179312949`와 동일한 링크입니다.
- `https://link.coupang.com/a/eg87vCOKSO`는 현재 `productId 8183985191`로 연결되지만 쿠팡 상품 응답이 403이라 상품명은 확정하지 않고 액세서리 목록에 보존합니다.
- productId 6530411186은 Apple 에어팟 2세대 유선 충전 모델 반품-중 링크로 확인했고, 수집 당시 쿠폰가 77,000원·재고 1개였습니다.
- productId 9205344492는 Apple 아이폰 17 자급제 화이트 256GB 반품-최상 링크로 확인했지만, 수집 당시 선택 옵션 재고는 없었습니다.
- 상품 페이지 접근이 차단된 경우에도 리다이렉트 URL에 드러난 식별자는 기록하지만, 상품명·가격·재고를 확인하지 못한 링크는 `가격 관찰` 또는 원문 제보로 남깁니다.

자동 요청은 쿠팡에서 차단될 수 있으므로, 이 프로젝트는 차단을 우회해 수집하지 않습니다. 브라우저에서 확인한 상품 링크를 보존하는 용도입니다.
